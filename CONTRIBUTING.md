# Contributing

SwiftSnips is a SwiftPM macOS app. Use full Xcode and run `swift test -c release` before proposing a change. For user-interface changes, inspect the running macOS window at its compact size with long, multiline, Unicode, and empty content.

Use synthetic snippets in tests and screenshots. Do not commit personal libraries, backups, signing identities, health files, captured typing, or clipboard contents. Keep changes focused and explain any new permission, process-launch, network, or file-system behavior in the pull request.
